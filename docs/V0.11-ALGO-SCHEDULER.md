# Minewhile algorithm scheduler

Production mode:

    ALGO_MODE=shadow

Standard YesPower remains the live mining algorithm.

The browser benchmarks supported YesPower variants in a temporary
Web Worker. The production worker continues to use the proven yp_hash()
path.

The relay uses Zpool profitability information to calculate a shadow
recommendation from:

- browser-measured H/s
- current profitability
- 24h profitability
- estimated network/pool size
- projected Minewhile fleet size

The recommendation is informational only.

Before enabling automatic switching, every algorithm must pass:

1. browser/native hash parity
2. correct pool endpoint/port
3. correct target conversion
4. server-side PoW validation
5. real upstream SHARE ACCEPTED
6. fallback test
7. scheduler cooldown/hysteresis test

Only then may ALGO_MODE move from shadow toward live switching.
